Welcome to the LeapMux user manual. LeapMux is a workspace for running several
coding agents and shell terminals at once — each in a git worktree and branch you
pick, tiled or floating, on a local or remote machine. Agent sessions stay attached
across restarts, and traffic to your agents is end-to-end encrypted.

This manual covers **getting started**, **workflow recipes**, **using** LeapMux day
to day, **operating** a deployment, and the **command reference**. Use the sidebar
to browse every chapter, or start with the cards below.
