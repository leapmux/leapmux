Welcome to the LeapMux user manual. LeapMux runs multiple coding agents and shell terminals side by side — each in a git worktree and branch you choose, tiled or floating, on a local or remote machine. Agent sessions persist across restarts, and traffic between your app and your agents is end-to-end encrypted.

This manual covers **Getting Started**, **Workflow Recipes**, **Using LeapMux**, **Administration**, and **Reference**. Browse the sidebar or start with the cards below.
